# COOLTOUR.KZ — адаптивный сайт о путешествиях по Центральной Азии

Туристический сайт с интерактивной картой, конструктором индивидуальных маршрутов и переходом в WhatsApp.

## Сайт на GitHub Pages

Репозиторий: https://github.com/kov717/testttt
Ссылка после публикации: https://kov717.github.io/testttt/

Ветка публикации: main; папка: / (root).

## Структура

- index.html — главная страница и все стили/скрипты
- img/ — локальные фотографии и запасные SVG-иллюстрации
- PHOTO_CREDITS.md — сведения об источниках фотографий
- .nojekyll — отключение обработки Jekyll

## Как включить GitHub Pages

Откройте **Settings → Pages** в репозитории GitHub.
Выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**.

После завершения публикации страница будет доступна по адресу https://kov717.github.io/testttt/.

## Возможности

- Адаптивное оформление для телефона, планшета и компьютера
- Казахстан, Узбекистан, Кыргызстан и Туркменистан
- Интерактивная визуальная карта с выбором достопримечательностей
- Готовое сообщение о выбранном маршруте в WhatsApp
- Переключение RU / KZ / EN

Стоимость, даты, доступность маршрутов и разрешения на посещение обсуждаются с принимающей стороной перед поездкой.
